# Cipher-Core Project

A modular operating system simulator and cryptographic utilities library.

## Components

- **alpha.c** - MiniOS operating system simulator
- **beta.c** - Extended kernel modules (klog, cron, network, syscalls, pipes)
- **gama.c** - Extended shell commands
- **delta.c** - Cryptographic utilities
- **epsilon.c** - Network protocol handler
- **zeta.c** - Thread pool implementation
- **eta.c** - Database abstraction layer
- **theta.c** - Event loop system

## Building

```bash
gcc -o cipher-core alpha.c beta.c gama.c delta.c epsilon.c zeta.c eta.c theta.c
```
